# Itadaki - Restaurant Client Android App

A modern restaurant ordering system featuring real-time synchronization via WebSockets.

## Overview

**Itadaki** (頂 - "to receive") is a comprehensive mobile application for restaurant order management. It features a modern UI with glassmorphism effects and optimized performance.

## Key Features

- **Real-time Sync**: Instant updates for Orders, Products, Users, and Roles via WebSockets.
- **Glassmorphism UI**: Modern blur effects and frosted glass design.
- **Optimized Performance**: 60 FPS animations with adaptive quality tiers.
- **Secure Authentication**: Robust user management and role-based access control.

## Tech Stack

- **Language**: Kotlin
- **UI**: Material Design 3, Jetpack Compose, XML Layouts
- **Networking**: Retrofit, OkHttp, WebSocket
- **Architecture**: MVVM with Hilt dependency injection
